# 空間點分布分析

[English](README.md) · [下載 Windows 版](https://github.com/LBK888/spatial_pattern_analyzer/releases) · [BibTeX](CITATION.bib)

分析二維座標在觀測區域內的排列。介面與 PDF 圖表可切換英文和繁體中文。

## 開始使用

1. 從 Releases 下載 Windows x64 EXE，雙擊開啟。使用原始碼時，請安裝含 Tk 的 Python 3.10 以上，先執行 setup.bat，再執行 start.bat。
2. 點「試用示範資料」，再點「執行分析」。示範資料有 9 個獨立樣本、18 個 ROI、1,296 個點，包含均勻隨機、聚集、規則排列三組，每組 N=3。A、B 標籤在各視野內隨機分配，資料表已提供實際矩形邊界。
3. 「組別圖」顯示樣本曲線及樣本間變異。「ROI 明細」可看單個視野的點位與包絡。「資料品管」列出需檢視的匯入和分析紀錄。點各設定旁的 ⓘ 可查看說明。

## 輸入與 ROI

支援 CSV、TSV、TXT、XLSX 和 XLS。對應 X/Y，並視需要選擇樣本 ID、ROI ID、點類型和組別。配對、區塊與四個矩形邊界欄位放在「更多欄位」。批次檔案共用欄位配置及工作表。未指定樣本 ID 時以檔名區分樣本，未指定 ROI ID 時每個樣本用一個視野。點和 ROI 都使用同一套 X/Y 校正係數；輸入邊界時請用原始座標。若短距離受定位或分割解析度限制，請設定有物理意義的最小半徑。

- **由點推估 ROI**。以可調鬆緊的凹包包住點群，點位曲線作描述性分析。固定位置的標籤置換仍可使用。
- **由點推估並固定邊界點**。使用凸包，模擬時固定觀測到的邊界點，只重新抽樣內部位置。在連續均勻抽樣及凸形支援區域的假設下，此檢定針對給定凸包後的內部排列。若要檢定整個觀測區，或視野有缺口、形狀不規則，請提供實際 ROI。內部點太少、有同座標事件或逐類型分析時，提供描述性結果。
- **矩形**。優先使用表格的 xmin、ymin、xmax、ymax。也可手動輸入共用範圍。請使用實際成像或裁切範圍。
- **自訂 ROI**。可載入平面 WKT、GeoJSON 多邊形與多重多邊形（支援孔洞）、PNG/TIFF 遮罩，也可在視野上繪製多邊形。GeoJSON 可用 sample_id 和 roi_id 指派各視野；無這兩欄的形狀、WKT 或遮罩可做共用 ROI。遮罩以非零像素作為 ROI，原點填左上角像素邊緣的原始座標。手畫多邊形只套用到所選視野。

程式會記錄無效座標、空白 ID、座標重疊和 ROI 外的點。預設保留重疊事件。可選擇移除同一樣本及視野內同類型的重複位置。完全重疊的座標可作描述性分析及標籤置換；連續位置 CSR 檢定不適用。品管資料列是匯入表格的邏輯記錄編號。

## 統計判讀

- **Ripley’s K 與 L**。矩形用平移校正，以有序相異點對及 n(n−1) 正規化。其餘形狀用縮減樣區校正，只有距邊界（包含孔洞）至少 r 的點能當焦點。無法估計的半徑保留為缺值。預設最大半徑為外接矩形短邊四分之一，不規則視野再依內部可用距離限縮。各曲線共用實際距離。K 的單位是長度平方，L = sqrt(K/π)，圖上顯示 L(r) − r。
- **全域隨機性檢定**。在同一 ROI 內固定點數，均勻且獨立地模擬位置，對整個半徑範圍使用雙側 95% 全域極端秩長度包絡。預設 999 次，種子可重現。相同排序採保守處理。超出上界表示該距離內的點對偏多，低於下界表示偏少。判讀同一輪的多個檢定時請使用 Holm 校正 p 值。未拒絕表示目前未偵測到偏離所選模型。
- **非均勻強度與跨類型**。已知矩形可匯入獨立取得的正值 CSV 強度矩陣。由較小 Y 往較大 Y 排列各列；同一矩陣套用至各矩形的相對位置。模擬和估計使用相同的固定強度。跨類型 K 則固定點座標，置換所選兩種標籤且保留各類點數。若總體點位置本身有梯度，請依標籤置換包絡解讀。
- **重複樣本**。先逐 ROI 計算，再將同一樣本內的有效 ROI 曲線平均。組別平均對獨立樣本等權。圖上細線代表樣本，粗線代表平均，N(r) 是每個半徑的有效樣本數。預設區間為 ±1 個樣本間 SD。進階可選逐半徑 95% 百分位 bootstrap CI，在所有樣本支援且 N≥3 的半徑重抽整條樣本曲線。只有一個樣本時可做 ROI 檢定，樣本間變異區間不適用。
- **組間比較**。在共同有效半徑顯示 A 組平均減 B 組平均。依設計在區塊內置換組別，或在配對內交換條件。虛無假設下須符合相應的可交換性。程式用原始差值曲線做全域秩檢定；依類型進行多個比較時使用匯出的 Holm 校正 p 值。
- **局部點位圖**。在選定的實際半徑，顯示觀測鄰居數減去 ROI 內均勻分布的期望鄰居數，色階以零為中心。圓面積以 96 邊形近似。這是單類型或所有點的描述性圖層。

## 匯出與重現

「匯出 PDF」保存目前檢視的圖，使用向量線條與內嵌可搜尋文字，方便後續用向量或 PDF 編輯器處理。繁體中文圖使用 Windows 已安裝的中文字型。「匯出資料」提供 Excel 活頁簿或 ZIP 中的 UTF-8 CSV。curves 是各層級曲線；summary 是檢定摘要與偏離尺度；metadata 包含匯入對應、座標校正、套件版本和種子；roi 是實際分析窗口的 WKT；qc 記錄需檢視的資料；local 保存選填的局部點結果。

論文方法可同時報告 ROI、座標校正、邊界校正、獨立樣本與視野數、半徑、虛無模型、模擬次數及多重比較處理。

## Windows 封裝

在隔離的 64 位元 Python 環境安裝 requirements.txt 與 PyInstaller，執行 build-windows.ps1，並以 -Python 指定該環境的直譯器。封裝流程執行測試、驗證 EXE 可輸出雙語 PDF 與 Excel，並將 SHA256.txt 放在 EXE 旁。授權為 MIT。
