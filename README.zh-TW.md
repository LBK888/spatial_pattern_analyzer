# 空間點分布分析

[English](README.md) · [下載 Windows 版](https://github.com/LBK888/spatial_pattern_analyzer/releases) · [BibTeX](CITATION.bib)

分析二維座標在觀測區域內的排列。介面與 PDF 圖表可切換英文和繁體中文。

## 開始使用

1. 從 Releases 下載 Windows x64 EXE，雙擊開啟。使用原始碼時，請安裝 Python 3.10 以上，先執行 setup.bat（自動安裝 PyQt6 與科學運算套件），再執行 start.bat。
2. 點「試用示範資料」，再點「執行分析」。示範資料有 9 個獨立樣本、18 個 ROI、1,296 個點，包含均勻隨機、聚集、規則排列三組，每組 N=3。A、B 標籤在各視野內隨機分配，資料表已提供實際矩形邊界。
3. 「組別圖」顯示樣本曲線及樣本間變異。「ROI 明細」可看單個視野的點位與 95% 模擬帶。「資料品管」列出匯入和分析紀錄。「ROI 圖解」以中英雙語圖示呈現各種觀測區域與邊界校正方式。

## 輸入與 ROI

支援 CSV、TSV、TXT、XLSX 和 XLS。Excel 活頁簿可一次勾選讀取多個工作表（分頁），並支援直接以分頁名稱作為實驗處理（組別），以及自動合併橫向並排的多樣品欄位區塊（或直接讀取標準 A–I 欄位）。對應 X/Y，並視需要選擇樣品編號（sample_id）、ROI ID、點的名稱（cell_type）和實驗處理（group）。配對、區塊與四個矩形邊界欄位放在「更多欄位」。當有多個樣本時，可啟用「固定 r 間距分切」（例如範圍 `0 ~ 250`、固定每 `2.5` 計算一次，共 `100` 個點），確保所有樣本在完全一致的半徑刻度上計算平均與變異度。點和 ROI 都使用同一套 X/Y 校正係數；輸入邊界時請用原始座標。

- **由點推估凹包ROI**。以可調鬆緊的凹包貼合點群。可改用凸包防收縮，或讓同一視野的各類型共用邊界。95% 全域模擬參考帶固定擬合出的 ROI，再與均勻模擬比較。固定位置的標籤置換仍可使用。
- **由點推估凸包ROI**。條件式 CSR 模擬固定觀測到的凸包邊界點，並重新均勻抽樣內部位置。此檢定採用凸形支援區域與連續均勻抽樣假設。內部點太少、座標重疊或點群無法形成凸包時，結果可能只有描述性曲線或參考帶。
- **矩形（由點群擬合）**。在每個視野點群的凸包或凹包內，擬合面積最大的 X/Y 軸對齊矩形。凹包使用網格搜尋與邊界細化近似求解。分析僅納入矩形內的點，排除的點會列入資料品管。半徑有足夠資料支援時，「ROI 明細」會顯示描述性模擬參考帶。
- **自訂 ROI**。使用表格的 `xmin`、`ymin`、`xmax`、`ymax`，或手動輸入共用的已知邊界。也可匯入 WKT、GeoJSON 多邊形與多重多邊形（支援孔洞）、PNG/TIFF 遮罩，或自行繪製。GeoJSON 可用 `sample_id` 和 `roi_id` 指派各視野。未指定視野的形狀、WKT 或遮罩可供共用。遮罩以非零像素作為 ROI，原點填左上角像素邊緣的原始座標。手畫多邊形只套用到所選視野。

程式會記錄無效座標、空白 ID、座標重疊和 ROI 外的點。預設保留重疊事件。可選擇移除同一樣本及視野內同類型的重複位置。完全重疊的座標可作描述性分析及標籤置換；連續位置 CSR 檢定不適用。品管資料列是匯入表格的邏輯記錄編號。

## 統計判讀

- **Ripley’s K 與 L 及多種邊界校正**。自動模式對軸對齊矩形使用平移校正，其他形狀使用縮減樣區校正。**平移校正**以位移後的重疊面積加權，**Ripley 同向性圓周校正**使用落在視野內的圓弧，**縮減樣區校正**隨半徑增加而限制可用的內部焦點。K 的單位是長度平方，L = sqrt(K/π)，圖上顯示 L(r) − r。
- **全域隨機性檢定與多核心獨立種子流**。每個 `(樣本, ROI, 點名稱)` 皆分配獨立確定性的 `SeedSequence` 亂數流並支援多執行緒平行運算，無論單獨執行或批次合併分頁執行，單一樣本的模擬檢定結果完全一致。
- **非均勻強度與跨類型全配對矩陣**。「自訂 ROI」的已知矩形可搭配自動或平移校正，匯入正值 CSV 強度矩陣。跨類型 K 可分析單組 `A → B`，也支援**跨類型全配對矩陣**，對各類型組合執行標籤置換檢定。
- **重複樣本與變異區間**。先逐 ROI 計算，再將同一樣本內的有效 ROI 曲線平均；組別平均對獨立樣本等權。可在介面即時切換 **平均值 ± SD**、**平均值 ± SE（標準誤）** 與 **95% 信賴區間（Bootstrap CI）**。當資料包含多種點名稱時，系統會同時計算各單一點分布與合併點群（如 `HRC + NaRC + NCC` 三種點合併，預設僅納入同時具備所有合併點名稱之樣本，亦可自訂任意兩種或多種點合併），並可自由勾選要繪圖與比較的分組（例如不同實驗處理的 HRC，或同一實驗處理的三種點分布比上三種點合併）。
- **組間生物統計檢定**。自動依樣品編號結構判斷實驗設計：不同實驗處理採獨立樣本檢定；同一處理內相同樣本集合採重複量測配對檢定；部分樣本共染重疊時採樣本叢集符號置換（Wild Cluster Resampling）與部分配對 $t$ 檢定（Derrick's partially-paired $t$）。曲線層級提供多組整體全域極端秩包絡檢定（Functional Permutation ANOVA $F(r)$）與事後兩兩差值曲線 $\Delta \bar{L}(r)$ 全域檢定（含 Holm–Bonferroni 多重比較校正與顯著半徑區間標示），同時附上曲線整合均值之母數檢定（Welch $t$、配對 $t$、單因子／重複量測 ANOVA）與無母數檢定（Mann–Whitney $U$、Wilcoxon、Kruskal–Wallis、Friedman）。
- **局部點位圖**。在選定的實際半徑，顯示觀測鄰居數減去 ROI 內均勻分布的期望鄰居數，色階以零為中心。圓面積以 96 邊形近似。這是單類型或所有點的描述性圖層。

## 匯出與重現

「匯出圖表」可將目前檢視存成向量 PDF、向量 SVG 或 300 DPI PNG；「批次匯出全部」可一鍵將完整統計 Excel 報表與所有實驗處理／點名稱分組圖表、事後比較曲線一次輸出至指定資料夾。「匯出資料」提供 Excel 活頁簿或 ZIP 中的 UTF-8 CSV。curves 是各層級曲線；summary 是檢定摘要與偏離尺度；metadata 包含匯入對應、座標校正、套件版本和種子；roi 是實際分析窗口的 WKT；qc 記錄需檢視的資料；local 保存選填的局部點結果。

論文方法可同時報告 ROI、座標校正、邊界校正、獨立樣本與視野數、半徑、虛無模型、模擬次數及多重比較處理。

## Windows 封裝

在隔離的 64 位元 Python 環境安裝 requirements.txt 與 PyInstaller，執行 build-windows.ps1，並以 -Python 指定該環境的直譯器。封裝流程執行測試、驗證 EXE 可輸出雙語 PDF 與 Excel，並將 SHA256.txt 放在 EXE 旁。授權為 MIT。
